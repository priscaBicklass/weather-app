# Weather Dashboard (Vue 3 + TypeScript)

**What this is:**  
A small, polished Weather Dashboard built with Vue 3 + TypeScript and Vite.  
It shows current weather for searched cities using the OpenWeatherMap API.

**How to use**

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a file named `.env` at the project root with your OpenWeather API key:
   ```
   VITE_OPENWEATHER_API_KEY=your_api_key_here
   ```
   (Get a free key from https://openweathermap.org if you don't have one.)
3. Run the dev server:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:5173` in your browser.
